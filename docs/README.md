# GreenLeaf AI Assistant

## Project Goal
Build an internal AI assistant for GreenLeaf Logistics that answers repetitive employee questions based strictly on approved company sources.

## Problem
Employees repeatedly ask HR and Operations the same questions about holidays, expenses, leave, and company rules. This creates avoidable interruptions and reduces productivity.

## Proposed Solution
We are building a reliable internal assistant that:
- answers only from approved sources
- avoids hallucinations
- shows the source of each answer
- respects company-specific rules, especially Basel-specific holiday logic
- does not expose sensitive information

## Key Requirements
- Accurate expense validation
- Basel holiday accuracy
- Security-first behavior
- Proof of source
- Clear scope and team workflow

## Repository Structure
- `docs/` project documentation
- `data/` source and processed project data
- `src/` technical structure for future implementation

## Sprint 1 Focus
- define scope
- define roles
- identify risks
- extract key rules from source material
