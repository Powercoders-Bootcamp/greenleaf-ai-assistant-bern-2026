# 03. Scope - MoSCoW Prioritization

## Must Have
- Answer based on handbook and approved source data
- Expense validation logic
- Basel holiday logic
- Clear source reference
- Safe handling of sensitive information

## Should Have
- Friendly and structured answer formatting
- Basic chat-style interface
- Clear fallback for unknown questions

## Could Have
- Multi-language support
- Direct links to specific source sections
- Better retrieval or search experience

## Won't Have
- Payroll processing
- Salary increase handling
- Physical logistics or tracking support
- Harassment / whistleblowing case handling inside the bot
- Sharing internal sensitive IT data
