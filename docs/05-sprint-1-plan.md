# 05. Sprint 1 Plan

## Sprint Goal
Create a clear project foundation and validate the first assistant logic on a limited set of high-priority use cases.

## Sprint 1 Priorities
1. Finalize team roles
2. Finalize project scope
3. Extract and structure handbook rules
4. Define the first user stories
5. Set up GitHub documentation and task tracking
6. Prepare a simple technical approach

## First User Stories
- As an employee, I want to know whether my lunch is reimbursable so that I do not submit an invalid expense.
- As an employee, I want to know whether a specific date is a holiday in Basel so that I know whether I need to work.
- As HR, I want the assistant to show its source so that I can trust the answer.
- As the company, I want the assistant to avoid answering unsafe or sensitive questions.

## Sprint Deliverables
- Team charter
- Scope definition
- Risks and assumptions
- Structured project repo
- Initial backlog
- First implementation direction
