# 04. Risks and Assumptions

## Assumptions
- The handbook is the main trusted source of truth
- Holiday data is correct and up to date
- The assistant should prioritize accuracy over completeness
- If information is missing, the assistant should not guess

## Technical Risks
- Incorrect data retrieval from handbook content
- AI hallucination
- Weak or missing source references
- Integration issues between backend and interface

## Team Risks
- Different skill levels in the team
- Some members not available because of schedule conflicts
- Too many ideas before defining scope
- Lack of clear ownership

## Mitigation Strategy
- Start with a simple MVP
- Validate answers manually against the handbook
- Keep decisions documented
- Assign clear responsibilities
- Align as a team before coding
