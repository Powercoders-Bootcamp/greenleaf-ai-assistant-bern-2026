## GreenLeaf Logistics - Beat-Bot

## Already Resolved Since This Snapshot

- login is required
- application roles are `Employee` and `Admin`
- role mapping should live in the application database
- app access is identity-based only for now
- all Wi-Fi password questions should be refused in MVP
- MAC registration details should not be disclosed
- expense handling is text-only for MVP
- the system may rely on user declaration for external-client presence
- Admin can review all employee chat histories and metadata
- employees can view only their own chat history
- voice input is out of MVP scope
- multilingual support is out of MVP scope
