# Scope and MoSCoW Prioritization

> Archive note: This is a historical prioritization snapshot. The active scope source of truth now lives in the numbered docs under `docs/`.

## GreenLeaf Logistics - Beat-Bot

## 1. Scope Position

Beat-Bot is a narrow internal policy assistant. It is not a full HR system, not a help-desk replacement, and not a general conversational bot.

## 2. Must Have

- simple text-based question input
- source-backed answers from approved documents
- safe refusal for sensitive IT and credential questions
- misconduct redirection to the ombudsman path
- authenticated access
- admin and employee role support
- chat-history persistence

## 3. Should Have

- clear refusal and redirect UX
- query and response logging
- basic evaluation with golden questions
- admin review visibility

## 4. Could Have

- friendly conversational polish
- limited multi-turn clarification
- voice input
- usage analytics
- suggested follow-up questions

## 5. Won't Have

- salary or compensation processing
- full HR case management
- logistics tracking
- external system integrations
- self-service Wi-Fi password disclosure
- MAC registration detail disclosure
- autonomous workflow execution

## 6. MVP Priorities

For the 3-week window, optimize for:

- expense correctness
- Basel holiday correctness
- citation quality
- refusal safety
- authenticated access and role visibility
