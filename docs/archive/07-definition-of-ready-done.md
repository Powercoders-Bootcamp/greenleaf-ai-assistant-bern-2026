# Definition of Ready (DoR) and Definition of Done (DoD)

> Archive note: This is a historical process document. It remains broadly valid, but active implementation details now live in the numbered docs under `docs/`.

## GreenLeaf Logistics - Beat-Bot

## 1. Definition of Ready

A story is ready when:

- purpose and scope are clear
- acceptance criteria are testable
- dependencies are known
- major unknowns are resolved
- the team understands the story

## 2. Definition of Done

A story is done when:

- acceptance criteria are met
- code is reviewed
- feature is tested
- no critical bugs remain
- responses are accurate and safe
- source references are correct where applicable
- security checks pass
- logs and validator outcomes are traceable
- documentation is updated

## 3. Special Rules for AI Features

- the system must not guess
- the system must answer only from verified sources
- the system must refuse unsafe or unsupported queries
- the system must validate structured drafts before release
